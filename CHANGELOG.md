# Changelog

## 0.1.0-alpha.1

First public alpha.

- Real-time beat tracking with tempo, beat phase, bar position and fast stop when music ends.
- Designs: Warp Tunnel, Pop Tunnel, Pop Tunnel II, Neon Geometry, Flux, Pulse Ring and Whistle Sketch.
- Desktop widgets: pinned into the desktop behind icons, always on top, or free floating; drag and
  resize in layout mode; positions are saved.
- Showcase window with live previews, 16 color palettes per widget, quality levels.
- Tray quick-settings flyout and a full settings window.
- Input from playback (loopback) or microphone; Whistle Sketch can use the microphone while the other
  widgets follow the music.
- Start with Windows.
